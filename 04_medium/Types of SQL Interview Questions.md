# Categories of SQL interview Questions for Data Scientists

1. Basic SQL Questions
: study a list of definitions of SQL terms and applications
- understanding the differences between joins
- what kinds of aggregations exist
- knowing the basic functions like CASE WHEN or HAVING
- COUNT of a table
- HAVING clause does
- how to utilize LEFT JOIN and INNER JOIN


2. Reporting and metrics SQL questions
- replicate the work that many business and reporting analysts do on a day-to-day basis --> end up in dashboards and key metrics
- require complex joins, sub-queries, window functions, and more
- ex. how many active users signed up


3. Analytics SQL questions
- understanding what metrics we need to answer the question
- writing the correct SQL query that will output these metrics


4. ETL SQL questions
- EXTRACT, TRANSFER, LOAD : the process for which data flows between different data warehousing system
- read data -> convert data -> write data into another database,table, or any other data storage service that can be then used by others for reporting


5. Database design questions
- knowledge of data architecture and design
- how to design a database from scratch
- how to modify our database to fit the new requirements
- solid initial design is important when building out db


6. Logic-based SQL questions
- trickiness of algorithms and data structure
